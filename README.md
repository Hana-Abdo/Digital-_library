# Digital Library System

This project is a Digital Library web application built using **Python Flask**.

## Project Notes
- This repository contains only the source code.
- The project is connected to Flask for backend logic and routing.
- Media files such as images, audio, and videos are not included to reduce repository size.
- Media files can be added locally if needed.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
